# CLI-приложение для управления базой данных фильмов

## Описание задачи

Создай CLI-приложение на Python для управления базой данных фильмов с использованием SQLite. Приложение должно предоставлять интерактивный меню-ориентированный интерфейс для работы с коллекцией фильмов.

## Требования

### Стек технологий
- **Язык**: Python 3.10+
- **База данных**: SQLite3 (встроенная в Python)
- **Формат данных**: CSV для импорта/экспорта
- **Аргументы командной строки**: sys.argv

### Структура проекта

```
project/
├── main.py           # Основной CLI-интерфейс и бизнес-логика
├── database.py       # Класс для работы с SQLite БД
├── import_csv.py     # Модуль импорта данных из CSV
├── imdb_top_250.csv  # Исходный CSV файл с данными
├── base.db           # SQLite база данных (создаётся автоматически)
└── .gitignore        # Файл игнорирования для Git
```

### Функциональные требования

#### 1. Класс Database (`database.py`)

Реализуй класс `Database` для работы с SQLite с以下ми методами:

**Управление подключением:**
- `__init__(db_path: str)` — инициализация пути к БД
- `connect()` — установка соединения
- `disconnect()` — закрытие соединения
- `get_connection()` — контекстный менеджер для получения соединения
- `get_cursor(commit: bool = False)` — контекстный менеджер для получения курсора

**Чтение данных:**
- `fetch_one(query, params)` — вернуть одну запись как словарь
- `fetch_all(query, params)` — вернуть все записи как список словарей
- `fetch_many(query, params, size)` — вернуть ограниченное количество записей
- `get_count(query, params)` — получить количество записей

**Вставка данных:**
- `insert_one(table, data)` — вставить одну запись, вернуть ID
- `insert_many(table, data_list)` — массовая вставка, вернуть количество

**Обновление данных:**
- `update_one(table, data, where_clause, where_params)` — обновить записи по условию
- `update_many(table, data_list, where_clause, where_params)` — массовое обновление

**Удаление данных:**
- `delete_one(table, where_clause, where_params)` — удалить одну запись
- `delete_many(table, where_clause, where_params)` — удалить множество записей
- `delete_all(table)` — удалить все записи из таблицы

**Управление схемой:**
- `execute(query, params, commit)` — выполнить произвольный SQL
- `executemany(query, params_list, commit)` — выполнить запрос с множеством параметров
- `create_table(table_name, columns)` — создать таблицу
- `drop_table(table_name)` — удалить таблицу
- `table_exists(table_name)` — проверить существование таблицы
- `get_tables()` — получить список всех таблиц
- `get_table_info(table_name)` — получить информацию о колонках таблицы

**Транзакции:**
- `begin_transaction()` — начать транзакцию
- `commit()` — подтвердить транзакцию
- `rollback()` — откатить транзакцию

**Вспомогательные методы:**
- `get_last_insert_id()` — получить ID последней вставки
- `vacuum()` — оптимизировать БД
- `integrity_check()` — проверить целостность БД

**Контекстный менеджер:**
- `__enter__()` и `__exit__()` — для использования в конструкции `with`

#### 2. Модуль импорта (`import_csv.py`)

Реализуй функции:
- `create_movies_table(db)` — создать таблицу `movies` со схемой:
  - `rank INTEGER PRIMARY KEY`
  - `title TEXT NOT NULL`
  - `year INTEGER`
  - `genre TEXT`
  - `duration TEXT`
  - `origin TEXT`
  - `director TEXT`
  - `imdb_rating REAL`
  - `rating_count INTEGER`
  - `imdb_link TEXT`

- `import_csv_to_db(csv_path, db_path)` — импортировать данные из CSV в БД:
  - Удалить старую таблицу если существует
  - Создать новую таблицу
  - Прочитать CSV файл
  - Вставить все записи批量

#### 3. Основной CLI (`main.py`)

**Бизнес-логика — функции для работы с фильмами:**

1. `find_movies_by_genre(genre, db_path)` — найти фильмы по жанру (использовать LIKE)
2. `delete_movies_older_than(year, db_path)` — удалить фильмы старше указанного года
3. `get_all_genres(db_path)` — получить уникальный список всех жанров
4. `get_top_movies(limit, db_path)` — получить топ фильмов по рейтингу
5. `get_movies_count(db_path)` — получить общее количество фильмов
6. `add_movie(title, year, genre, imdb_rating, imdb_link, db_path)` — добавить фильм
7. `find_movies_by_title(search_word, db_path)` — найти фильмы по подстроке в названии
8. `get_top_movies_after_year(year, limit, db_path)` — получить топ фильмов после указанного года

**Интерактивные функции:**

Для каждой операции создать интерактивную версию:
- `interactive_search_by_genre()` — выбор жанра из списка, показ результатов
- `interactive_delete_old_movies()` — ввод года, подтверждение, удаление
- `interactive_add_movie()` — пошаговый ввод всех полей фильма
- `interactive_show_movies_count()` — показать количество фильмов
- `interactive_show_top_movies()` — ввод количества, показ топ фильмов
- `interactive_search_by_title()` — ввод слова, поиск по названию
- `interactive_show_top_movies_after_year()` — показать топ фильмов после 2015 года

**Импорт/экспорт:**
- `import_database_from_csv(csv_path, db_path)` — перезагрузка БД из CSV с подтверждением

**Меню:**
- `print_menu()` — вывод основного меню с опциями:
  1. Поиск фильмов по жанру
  2. Удалить фильмы старше года
  3. Добавить новый фильм
  4. Показать количество фильмов в базе
  5. Топ-5 фильмов по рейтингу
  6. Перезалить БД из CSV
  7. Поиск фильма по названию
  8. Топ-10 фильмов после 2015 года
  0. Выход

- `main_cli()` — главная функция CLI-интерфейса с циклом меню

**Запуск приложения:**
- Обработка аргументов командной строки:
  - `--cli` или `-c` — запустить интерактивный CLI
  - `--delete-old` — запустить удаление старых фильмов
  - Без аргументов — запустить CLI по умолчанию

### Технические требования

1. **Обработка ошибок:**
   - Валидация пользовательского ввода (числа, пустые значения)
   - try-except блоки для всех операций с БД
   - Информативные сообщения об ошибках

2. **Логирование:**
   - Настроить logging в `database.py`
   - Логировать ключевые операции (подключение, запросы, ошибки)

3. **Безопасность:**
   - Использовать параметризованные запросы (защита от SQL-инъекций)
   - Контекстные менеджеры для автоматического закрытия ресурсов
   - Rollback при ошибках в транзакциях

4. **Код:**
   - Типизация (type hints)
   - Docstrings для всех функций и классов
   - Следование PEP 8
